# Medical-Pro
**AI-Powered Clinical Assistant for Godot 4**

Medical pro is a specialized medical transcription tool built with Godot 4. It leverages the **Gemini 3.1 Flash-Lite** API to convert raw patient-doctor transcripts into structured, professional **SOAP notes** (Subjective, Objective, Assessment, Plan).

##  Features
* **Real-time AI Processing**: Instant transformation of medical dialogue.
* **SOAP Note Formatting**: Automatically organizes data into clinical standards.
* **Decoupled Architecture**: Built using modular GDScript signals for easy scaling.
* **2026 Edge Tech**: Optimized for the latest Gemini 3.1 inference engine.

##  Tech Stack
* **Engine**: Godot 4.x
* **Language**: GDScript
* **AI Backend**: Google Gemini API (March 2026 Production Build)
* **Version Control**: Git / GitHub
